Informativa sulla privacy

Applicazione: Sincronizzazione LAVORO

Finalità del trattamento

L'applicazione è destinata all'utilizzo personale del proprietario degli account e utilizza Rclone per sincronizzare file tra Google Drive e Microsoft OneDrive.

Dati consultati

L'applicazione accede ai file, alle cartelle e ai relativi metadati mediante autorizzazione OAuth 2.0, esclusivamente per le operazioni di sincronizzazione autorizzate.

Utilizzo e condivisione dei dati

I dati vengono utilizzati per la sincronizzazione tra gli account cloud autorizzati. Non vengono venduti, utilizzati per finalità pubblicitarie o ceduti a soggetti estranei al servizio.

Sicurezza e conservazione

Le credenziali di autorizzazione sono conservate nella configurazione locale di Rclone. Questo sito informativo non ospita file sincronizzati o credenziali di accesso.

Revoca e cancellazione

Il proprietario può interrompere la sincronizzazione, revocare le autorizzazioni dalle impostazioni dei propri account e cancellare la configurazione locale. I file rimangono nei servizi cloud fino alla loro eventuale cancellazione.

Conformità alle norme Google

L'utilizzo dei dati ricevuti dalle API Google rispetta la Google API Services User Data Policy, inclusi i requisiti Limited Use.
